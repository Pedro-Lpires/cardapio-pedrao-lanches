# Source Sans 3

Fonte variável oficial da Adobe, usada nos títulos e descrições dos produtos.
Os arquivos ficam no próprio projeto, sem depender de serviços externos de fontes.

- Projeto: https://github.com/adobe-fonts/source-sans
- Arquivo: `WOFF2/VF/SourceSans3VF-Upright.ttf.woff2`, branch `release`.
- Licença: SIL Open Font License 1.1, incluída em `LICENSE.md`.
